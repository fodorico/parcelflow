# Future ideas

Out of the current scope; revisit when planning new phases.

## From the brief (deferred)

- Longer-distance shipments inside a country (carriers, hubs, longer time windows): "local" now
  covers the whole country, but this may need its own logistics flow.
- International shipments between the demo countries or others (customs data, duties,
  documents, carrier handoff).

## Possible additions

- Public tracking page by tracking code (no login).
- Address autocomplete and geocoding.
- Package details: size, weight, fragile, declared value, insurance.
- Courier availability, shifts and vehicle type; automatic assignment suggestions.
- Customer ratings and feedback after delivery.
- Customer support chat / incident reporting (failed delivery, damaged package).
- Multi-tenant mode (several logistics companies on the same platform).
- Offline support for the courier app (queue status updates without signal).
- Audit log of admin actions.
